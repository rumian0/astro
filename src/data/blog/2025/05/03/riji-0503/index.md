# 茗述

## 学校读书日

这是学校第一年的读书会,有的项目很多,有答题,写字,古筝,茶艺,歌舞,还有文学跳蚤市场,听说这次回来媒体,如果逮到我们让我们不要乱说话😂 ,主要的流程就是,先去答题,总共有六道,如果全部答对就可以获得一个终极奖品,也有一等奖二等奖,说是一等奖特别难获得.

在这个活动中每个人必须着汉服,对于我这个没什么特别服饰的人,哪来的什么汉服? 仅仅有我三年级时买的西装,哈哈哈! 放到现在都小了,所以我肯定是用不了了,但不穿汉服又不让参加,老师是周末通知的信息,而周三就是表演,现在订肯定来不及(新疆快递6天送达),那怎莫办呢,老师让家长来送,而家长送的我们可能又不喜欢,自己有不能出校门去买,因为我们是寄宿学校.....

都到了周二晚上了,班主任提出,不如我们派出去几个同学,帮我们挑服饰,记录号每个人的身高尺寸他们就出发了.带着我们的希望! 他们出去之后,给我们晚自习的老师打视频,之后我们自个选服饰,就更拍卖会一样🤣,你要这个服饰吗? (不要),这个龙袍怎么样?(挺好看的,那我买.....?)(别问了这个我要了!)这场面堪比XXX(认知有限了),我挑了一个古代文人的服饰,也不是皇帝的,跟我想的一样,我也就是想要这种看起来阳光的服饰,宫廷的勾心斗角我们又不是没学过,皇帝的阴险狡诈,又不是没见过,到时候身着龙袍有人说,这不是秦始皇,哈哈哈!得亏我比较理智,一个书香文章,再配上我这个看着还行,一拍就废的人,很符合我,哈哈哈!

第二天早上,衣服就已经摆在了我的桌子上,看着还行!但我觉得那肯定可以啊!(毕竟80一天租下来的....),中午吃完饭后就去换衣服了,我看着就很有书香富家门第的样子,哈哈哈!只不过学校不让带手机没办法喽!那天的树上连个好多绳子,每个绳子上面有55道题,只需要及其不同颜色的5道题去找老师达就可以获得一个印章,机器5个再去兑换终极大奖,一道题就可以获得一等奖!

看起来很简单是不是,有个题`<百年孤独>中比一代男主的名字叫什么?`  我第一个想到是**阿尔卡蒂奥·布恩迪亚**,我去问别人他说叫**奥雷里亚诺**,这不是他儿子,难不成我记错了,难不成是**奥斯特洛夫斯基**?(这不是写钢铁是怎样炼成的吗?)

之后 相信我,终极大奖我肯定到手了,是一个手提包,上面刻着``脚步到达不了的地方,文字可以!`,非常有纪念意义!!

## 研学

这次研学去的地点是农博园,里面我们了解了许多的植物种,花种,去了海洋馆,去了昆虫馆,不过不太好玩,有些场馆都关门了,有的甚至要买门票,不过我们倒是拍了很有意思的照片,了解到了女生为什么这么喜欢拍照,哈哈哈,是学会很多,也是挺有趣,不过这个场馆特别大! 走起来特别累,得亏有个小车,扫个码就能骑,这感觉不要太爽了,全是风与自由,由于我是白嫖 的,所以我要坐在最前面,哈哈哈,简称"龙头"! 总之逛着逛着这个院子就不是用来欣赏农业物了,而是尽情的玩耍了,骑车了,哈哈哈!

之后我们去了小吃街,到哪里好朋友请我们吃**雪花凉**!! 这东西就像吃冰,量特别多,入口阵阵冰凉传来,给我们30多度的脑壳降了降温,再配上新鲜牛奶 +白砂糖!**爽!**不过10元一份,属实不能接受,这么一大碗,我就吃下去了1/6  ,量真的大,但会不会拉肚子我就不知道了,哈哈哈!再去吃个

小吃街的后面就是国家公园,公园就更游乐园一样,里面海盗船,大摆锤,跳楼机,卡丁车.....全玩了一遍,我们就回去了!当然也拍了照,只不过博主没带手机,都人家相册里,我也不方便去要.

原本想着放几张我的合照来着,但是.....本人 不太喜欢露脸😂,下次一定,有帅照了一定放,哈哈哈!

谁能想,还没回家,成绩就已经 全部出来了,除了语文比较慢.....
